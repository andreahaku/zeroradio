## Bundled programs

These run as separate programs next to the apps. Their full source is available at the addresses below, at the version shipped.

- readsb 3.16.16, ADS-B decoder by wiedehopf and contributors. GPL-3.0. github.com/wiedehopf/readsb
- AIS-catcher 0.70, AIS decoder by jvde-github and contributors. GPL-3.0. github.com/jvde-github/AIS-catcher

## Libraries

- LVGL 9.5, embedded graphics library. MIT.
- {fmt} 10, formatting library. MIT.
- nlohmann/json 3.11, JSON for modern C++. MIT.
- FFTW 3, fast Fourier transform, used by the SDR app. GPL-2.0-or-later.

## Installed with the package (Debian)

- rtl-sdr (rtl_tcp, rtl_power, librtlsdr). GPL-2.0-or-later.
- rtl_433, ISM band decoder by Benjamin Larsson and contributors. GPL-2.0-or-later.
- HackRF tools (hackrf_sweep). GPL-2.0-or-later.
- PipeWire ALSA plugin, audio output.

## In the source repository only
